# 支付文档

在线支付用于用户自助充值。管理员配置服务商实例、可见支付方式、限额和回调；外部系统的管理集成使用 Admin API。

| 文档 | 用途 |
| --- | --- |
| [支付配置（中文）](PAYMENT_CN.md) / [English](PAYMENT.md) | 支付宝、微信、EasyPay 和 Stripe，实例管理、可见方式与 Webhook |
| [Admin 支付集成 API](ADMIN_PAYMENT_INTEGRATION_API.md) | 创建并兑换充值码、用户查询、余额调整及页面 query 透传；含中英文说明 |

支付服务商的资质、费用和结算条件以服务商实际规则为准。项目文档说明配置与协议行为，不提供服务商推荐或费率承诺。
