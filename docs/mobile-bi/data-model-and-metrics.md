# 数据模型与指标口径

## 唯一来源

企业和成员来自 `desktop_organizations`、`desktop_members`；用量直接查询 `usage_logs`，复用历史 `desktop_member_api_keys` 与独立日报分析密钥关联。原始会话和日报使用现有 Desktop repository。新 BI 不复制事实、不使用 Connector 或 AnalysisContext。

小程序只返回安全 DTO：不包含手机号、密钥、内部原站账号、安装标识、本地目录、费用排行或执行诊断。已删除成员保留有本期用量的历史目录项。管理员的运维计费与小程序读取分开。

## 周期与数字

用量和会话选近 7／30／90 天，包含今天，统一 Asia/Shanghai。用量按日志时间，会话按接收时间；日报按结束日期。各 API 返回实际范围和更新时间，不把三者解释为同一个事件集。

- **有用量成员**：所选期间关联历史成员密钥的实际用量日志人数，不等同活跃、采用率或绩效。
- **有上报记录成员**：所选接收期间有会话上报的去重人数，不等同主动交互或任务完成。
- **Token**：字符串传输与显示。总量为输入、输出及日志独立缓存桶；显示的输入已合并缓存桶，缓存子项不得再相加。
- **分析用量**：独立日报分析密钥产生的用量，单列为总量的子项。
- 无日志为真实 `"0"`；存在日志但无法计量为 `null`，显示「—」。有不可观测请求时标注「已观测」与请求数量。
- 模型列表完整分页，汇总独立 SQL 查询；不从已加载页数或 Top 10 反推总量。

前期范围保留相同天数和当天已结束时间，不合并去重人数。数据不能可靠区分人员主动交互和自动运行，因此不构造此类生产数组。

## 保留的 BI 设计

采用／稳定／留存须有完整适用母体与主动交互；部门岗位须有真实组织维度；企业应用与业务场景须有显式映射；知识复用须有有效知识、版本、引用关系；评估须区分通过、失败、未执行、不可比及受限样本。

当前上述数据未接入，生产页面保留结构和原因说明，不展示虚构数值。H5 的固定演示用于理解设计，不能作为企业真实数据或完成证据。
