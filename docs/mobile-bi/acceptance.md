# 验收标准

## 必须通过

- 独立微信身份没有原站账号也可登录；不创建原站用户，不关联员工身份。
- 一企业多使用者；一使用者多企业、不同功能权限；负责人隔离与平台权限分开。
- 邀请过期、撤销、并发、重放、重复加入不扩权；企业撤权后不可自助恢复。
- session refresh replay 会实际提交撤销；主动退出与迟到响应不恢复内容或凭证。
- 缺权限模块不发请求，不阻塞已授权模块；切企业／周期／返回保持正确范围。
- 用量字符串与服务端对账；缓存不重复相加；历史密钥、删除成员和完整分页可读。
- 周月自然周期、部分／无来源、冻结来源、更新提示、历史版本、去重、租约恢复、预算与计费。
- canary：周月输入仅有企业日总结；运维 SQL 与 DTO 不返回正文、输入及中间输出。
- 新库与旧 BI 开发数据升级通过；Desktop、用户、计费和配置保留。
- 旧接口／Worker／CLI 无运行调用；文档路由映射与 OpenAPI 相符。
- 后端 unit／integration／build／lint、后台 typecheck／tests／lint:check／build、小程序 typecheck／tests／weapp／H5 build。

## 分开记录

代码实现、本地 Go／TS HTTP 联调、H5 演示、小屏和长内容、微信模拟器、真机、容量、生产数据与生产部署。未执行项目标记未验证，不因本地构建成功改为完成。

费用 ROI、绩效排名、完整知识编辑器、额外来源系统不在本轮范围。未来 BI 设计保留为未接入，不能用用量或会话代替其业务指标。
