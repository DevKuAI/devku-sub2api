## 文档契约检查

在仓库根目录运行：

```bash
python3 -m venv /tmp/devku-contract-check
/tmp/devku-contract-check/bin/pip install -r docs/api/tools/requirements.txt
/tmp/devku-contract-check/bin/python docs/api/tools/validate_contract.py
```

检查OpenAPI 3.1合法性、所有本地引用、operationId唯一、路径参数和安全方案、每个操作请求/响应示例、示例里的错误状态、页面动作映射、文档相对链接，以及Token转换/指标样例约束。无需企业凭证或生产连接。

## 权限与并发测试

| ID | 操作 | 通过标准 |
| --- | --- | --- |
| P01 | 用户A使用用户B或企业B的context/对象/游标 | 403/404；不得返回标题、客户、统计或计数 |
| P02 | viewer读取成员、尝试copy/share/create | 有能力才允许，UI隐藏不代替服务校验 |
| P03 | 知识可见但来源无权 | 通用受限占位；搜索摘要/样本/报告不得旁路 |
| P04 | 切换企业或周期后旧请求晚到 | 不覆盖新页面；缓存键含企业/权限/data revision |
| P05 | 创建报告响应丢失、同key重试、同key异体 | 相同报告ID；异体409；只能创建一次 |
| P06 | note同时两端编辑/创建/删除 | 条件头语义标准；失配412、缺头428，保留草稿 |
| P07 | report生成后撤团队权限、来源撤回 | 历史报告/分享/text重新校验并拒绝，不返回缓存正文 |
| P08 | 分享给无权同事或其他企业；share过期/撤销 | 统一404；知道share_id不能授权 |
| P09 | 未绑定、无管理企业、204未配置、企业停用 | 无数据访问能力；不创建示例企业、不用员工登录绕过 |
| P10 | wx code重放、错AppID、票据过期、跨账号码、refresh并发 | 失败且无越权会话；未审批202有轮询间隔；凭证不落日志 |
| P11 | 来源ACL收紧同时索引缓存仍旧 | 搜索仍逐条授权；旧context不得继续访问来源 |
| P12 | 接入凭证向其他source/企业写入、导入管理角色 | 拒绝；不能通过同步权限升级 |
| P13 | 收藏/反馈已失权知识 | 不返回知识正文；允许本人清除自己残留数据 |
| P14 | 分页期间插入/删除/权限变动 | 不重不漏快照页；ACL变更重新建快照，不暴露失权对象 |
| P15 | 持有企业A高权限、企业B只读；在B尝试创建/分享 | 按B的capabilities判定；User权限并集不能用于放行 |
| P16 | 知识不可见但来源ACL可见；伪造父关系读取来源 | getSource校验parent_kind/parent_id及真实引用，统一404；不返回来源标题 |
| P17 | 分享创建者被撤权，但接收者仍有报告权限 | resolveShare统一404；只读者不能列出分享链接 |
| P18 | 同source并发新批、旧checkpoint、凭证轮换后重放 | 新批IMPORT_BUSY；旧游标CHECKPOINT_CONFLICT；同键同体返回原批，不重复应用 |
| P19 | 初次回灌无水位；批次拒绝；构建索引时进程退出 | 可用null水位且backfill=false；失败不推进；恢复后原子发布，旧读取无半批数据 |
| P20 | 同微信同时被两个管理账号确认；解绑后兑换旧挑战 | 仅一个绑定；另一个409；旧挑战失效，不重新绑定已解绑账号 |
| P21 | 模型/成员应用/反馈应用超过100条 | limit/cursor翻页完整；汇总跨页不变；末页next_cursor=null；不能跨实体复用游标 |
| P22 | 来源完全不可用、真实无调用、无知识权限 | 分别为相关计数null、已确认0、Overview.assets=null；不混淆三种状态 |
| P23 | 先读知识v1来源，再发布来源v2、关闭知识v1有效期 | 旧父关系仍读v1来源；正文不能被新版本覆盖；当前ACL撤权后所有版本拒绝 |

## 真实接入与移动设备验收

1. 测试租户导入能覆盖上述情形的脱敏样本，逐维度核对查询和事件账本。
2. 按[页面交互映射](./interaction-map.md)逐项操作；上周、本周、上月与组织/应用/场景交叉验证。
3. 演示入口与真实入口明显隔离，断网或500不出现演示数值；每个partial/null原因可见。
4. 两台设备验证收藏与note持久化，冲突处理；退出、重新wx.login、解绑与撤权后缓存清理。
5. 微信开发者工具与iOS/Android微信真机分别验证安全区、键盘、返回栈、前后台恢复、分享、复制和深链登录回跳；浏览器验证不替代这一步。
6. 压测目标与时间预算见PRD；按服务层日志核对p95、超时和数据版本，不仅测浏览器静态加载。
7. 接入成功的停止条件：全部P0交互及A/P用例通过，未完成项明确列出且不得标上线可用。AppID、合法域名与真实企业账号由实施环境提供，本轮不凭空填写。
