# 页面与交互

| 页面 | 已接数据 | 保留未接入设计 |
| --- | --- | --- |
| 总览 | 用量成员、Token、分析用量、上报成员、趋势、客户端、日总结 | 采用、稳定使用、留存、知识复用和评估 |
| 团队 | 成员姓名搜索、状态、周期用量、模型明细、会话、日报 | 部门与岗位比较 |
| 应用 | WorkBuddy／ChatGPT Codex 上报和企业模型用量 | 企业应用、Agent、Skill、工作流采用 |
| 场景 | 实际会话问题与响应 | 业务场景分类、任务完成和绩效 |
| 总结 | 日／自然周／自然月，归档版本、冻结来源、获权复制 | 受控分享和 BI 管理简报生成 |
| 搜索 | 成员姓名，300ms 防抖 | 知识、案例与独立来源搜索 |
| 设置 | 微信独立身份、企业选择、邀请确认、退出、隐私说明 | 收藏和反馈服务 |

登录和数据加载分离。没有企业授权时给出领取邀请入口；仅有某一功能权限时，其他模块显示无权限，不发请求，也不阻塞已授权模块。

每模块独立加载、失败和重试。列表按需分页；详情和来源点击后读取。改周期、切企业、退出及撤权清除内容并使在途响应失效；返回保留所选企业和近 7／30／90 天范围。

未知「—」、真实零、未启用、未接入、无权限和读取失败分别呈现。生产失败不回退演示。H5 与小程序共用同一套页面组件，使用独立的本地 DTO transport，明确标记演示内容；布局、筛选、分页、详情、总结来源和设置流程同步，不访问微信或企业服务。
