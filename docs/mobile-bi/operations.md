# BI 运维

## 页面边界

概览、企业接入、身份与邀请、总结任务、审计与保留。入口不依赖 `ops_monitoring_enabled`，BI 未启用时仍可查看概览并进入配置／隐私说明。

分别核对服务启用、微信凭证、独立 JWT／身份密钥、隐私发布、Desktop 服务、企业启停、会话上报、总结模型和周月自动开关。bootstrap 可读不等同功能已启用。

企业详情和运维复用邀请／使用者组件；原站负责人只管理自己的企业，平台管理员可管理所有企业。邀请码只在创建时返回，操作者自行发送。修改访问用 revision 保护；撤销企业访问与禁用全局身份分开。

## 总结任务

显示类型、周期、状态、版本、来源数量、模型、Token 字符串、费用、原因和执行记录。SQL 与 DTO 不选择正文、输入快照及中间输出。查看正文跳转企业后台，继续执行原业务权限，不通过 metadata 绕过鉴权。

不提供旧数据源、凭证、导入、水位质量、BI 独立报告或事实保留入口。

## 保留与清理

BI 清理只处理过期 refresh／session／邀请、临时微信兑换状态及 BI 审计，使用独立保留策略。Desktop 会话、报告和执行使用企业策略。不要全库 reset、跨模块 CASCADE 或修改已应用 migration checksum。

本轮旧 BI 清理对象在 migration 257 逐表列明。先在隔离数据库验证升级，发布部署须独立授权；开发代码准备完成不代表真实运行库已清理。
