# 企业周月总结

周总结直接使用该周企业日总结，月总结直接使用该月企业日总结。两者不读取成员归集正文、原始会话或彼此的内容。

## 周期与自动任务

Asia/Shanghai 完整自然周（周一至周日）及自然月；仅允许已结束周期，默认上周、上月。企业 `weekly_summary_enabled/monthly_summary_enabled` 默认 false，要求会话上报、企业日总结和分析模型已配置。

启用后周一／每月第一日 03:00 入队；重启在到期后补检最近结束的周期，不回灌全部历史。SQL 按企业、类型、周期及版本去重，一个周期最多一个活动任务。

## 来源、版本与恢复

至少一份可用日总结时可生成 partial，展示可用、部分、缺失和无上报日期及原因。全部无可用来源时进入等待，不调用模型；缺失不能解释为没有工作。

捕获时冻结日总结正文、日期、版本、状态、生成时间、覆盖和指纹。retry 沿用快照与成功 checkpoint，regenerate 创建新版本；旧结果保持可读。日总结变化只返回 `source_changed`，管理员选择重生成，不自动覆盖或调用模型。

生成复用现有日总结的 gateway、预算、分块归并、租约、恢复与执行计费路径。活动任务续租，丢失租约后停止保存；每次模型调用有独立执行记录，失败和已计费调用也留痕。

正文与输入快照采用企业报告保留策略；执行记录采用执行保留策略，可在正文清理后继续保留。活动任务及有效租约受保护。BI 身份清理不会处理 Desktop 报告内容。

企业后台展示正文、来源、版本和生成控制；小程序读取已有内容并获权复制。运维只查询安全 metadata，正文跳转企业后台读取。
