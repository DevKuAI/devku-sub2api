# 企业账目

账目按企业、币种分别管理，资金、应收、凭证和成本具有不同的业务含义。

## Language

**到账（Receipt）**：已实际收到的客户资金。应收金额和销售金额不能由到账金额替代。

**应收（Receivable）**：企业依据合同或业务单据应支付的金额，可由多笔到账分次核销。

**核销（Settlement）**：将已确认到账中的金额归属到指定应收，用于计算已收、未收和超期情况；不再次增加资金。

**账面余额（Book balance）**：依据已确认资金记录计算的余额。服务商余额是外部卡服务商提供或确认的余额，两者需要核对。

**VCC 分配（Allocation）**：将企业可用资金指定为卡片消费的资金来源，保留资金来源和释放历史。

**成本分摊（Cost allocation）**：将账单金额归属到对应消费或支出，同一实际成本只能计入一次。

**换汇（FX exchange）**：以明确汇率将一笔原币资金转换为目标币资金，费用单独记录，不形成新的客户销售收入。

**月结（Period close）**：对企业自然月的账务结果形成固定对账单，并限制该期间账务变更。

**重新开账（Reopen）**：经管理员授权并填写原因后，允许已结期间继续处理账务；已有对账单版本仍保留。
